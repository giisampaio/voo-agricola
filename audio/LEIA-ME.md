# Falas gravadas

Coloque aqui um arquivo `.mp3` para cada fala. O jogo toca o áudio junto com o balão de texto; sem o arquivo, a fala fica só no texto.

| Arquivo | Fala |
|---|---|
| `eliseu-trabalhar.mp3` | Piloto, trabalhar, piloto! |
| `eliseu-falir.mp3` | Ê, piloto, vai me falir! Tá jogando veneno no vento! |
| `eliseu-bao.mp3` | Ó, piloto bão! |
| `eliseu-ruim.mp3` | Ó, piloto ruim, meu Deuuus! |
| `eliseu-rico.mp3` | Ó, piloto vai ficar rico! |
| `eliseu-recarrega.mp3` | Recarrega e volta pro serviço, piloto! |
| `eliseu-fim-1.mp3` | Parabéns, piloto! Pousa aqui, vem tomar café da fazenda! |
| `eliseu-fim-2.mp3` | Serviço fechado, piloto! O café já tá passado. |
| `eliseu-fim-3.mp3` | Aí sim, piloto! Pousa que tem bolo de milho. |
| `eliseu-missao-2.mp3` | Talhão 4, piloto. Olha a mata no fim da faixa! |
| `eliseu-missao-3.mp3` | Talhão 9. Tem rede do lado, piloto! |
| `eliseu-missao-4.mp3` | Iracema, Talhão 2. Rede no fim da faixa! |

Formato: mp3, mono, sem silêncio no começo. Depois de colocar os arquivos, envie para os ramos `main` e `gh-pages`.
